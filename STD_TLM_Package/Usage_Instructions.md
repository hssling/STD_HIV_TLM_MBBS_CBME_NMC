# Usage Instructions for STD TLM Package

## Quick Start Guide

### For Educators
1. **Unpack the Package**: Extract all files to a dedicated folder
2. **Check Requirements**: Review Technical_Requirements.md
3. **Test Environment**: Open Implementation_Guide.md for setup instructions
4. **Start Teaching**: Begin with the class script in Scripts/ folder

### For Students
1. **Access Materials**: Open handouts and interactive materials
2. **Follow Along**: Use during class sessions
3. **Practice**: Complete quizzes and interactive exercises
4. **Review**: Use materials for self-study

## Detailed Usage Instructions

### Classroom Implementation

#### Pre-Class Setup (15 minutes)
1. Set up projector and computer
2. Open presentation file (Presentations/STD_Class_Presentation.pptx)
3. Test interactive materials in browser
4. Prepare handouts for distribution
5. Ensure Python environment is ready for visualizations

#### During Class (60 minutes)

**Introduction Phase (0-10 minutes)**
- Welcome students and outline objectives
- Use slides 1-3 from presentation
- Distribute handouts

**Core Teaching Phase (10-40 minutes)**
- Present STD epidemiology and classification (slides 4-8)
- Show visualizations using std_visualizations.py
- Discuss bacterial and viral STDs
- Use video script for multimedia content

**Interactive Learning Phase (40-50 minutes)**
- Launch interactive materials:
  - clickable_diagram.html for anatomical learning
  - symptom_checker.html for diagnostic practice
  - case_study_decision_tree.html for clinical reasoning
- Group activities using role_playing_counseling.html

**Assessment Phase (50-55 minutes)**
- Administer STD_Formative_Assessment_Quiz.py
- Discuss answers and clarify concepts

**Conclusion Phase (55-60 minutes)**
- Summarize key points
- Assign homework using interactive_quiz.html
- Q&A session

### Interactive Materials Usage

#### Clickable Diagram
- Open clickable_diagram.html in web browser
- Click on different anatomical areas
- Read pop-up information
- Use for self-paced learning

#### Symptom Checker
- Access symptom_checker.html
- Select patient symptoms from checklist
- View differential diagnosis
- Learn about STD manifestations

#### Case Study Decision Tree
- Open case_study_decision_tree.html
- Read patient scenario
- Make diagnostic and treatment decisions
- Receive feedback on choices

#### Treatment Simulator
- Launch treatment_simulator.html
- Simulate treatment regimen selection
- Monitor virtual patient progress
- Learn about treatment monitoring

#### Interactive Quiz
- Open interactive_quiz.html
- Answer questions progressively
- Receive immediate feedback
- Track learning progress

#### Gamified Prevention Game
- Access gamified_prevention_game.html
- Make prevention decisions in scenarios
- Earn points for correct choices
- Learn prevention strategies

#### Multimedia Timeline
- Open multimedia_timeline.html
- Explore historical STD developments
- Interactive timeline navigation
- Connect past to present

### Python Script Usage

#### Running Visualizations
```bash
cd Visualizations
python std_visualizations.py
```

#### Running Quizzes
```bash
cd Quizzes
python STD_Formative_Assessment_Quiz.py
```

### Offline vs Online Usage

#### Offline Mode
- All materials work without internet
- Interactive HTML files run locally
- Python scripts execute locally
- Presentations viewable offline

#### Online Mode (Recommended)
- Enhanced interactive features
- External libraries load faster
- Analytics and updates available
- Cloud backup possible

## Troubleshooting Common Issues

### Technical Problems
- **Scripts won't run**: Check Python installation
- **HTML won't load**: Verify browser settings
- **Images missing**: Check file paths
- **Presentations corrupted**: Use compatible software

### Educational Issues
- **Students disengaged**: Start with interactive elements
- **Content too complex**: Break into smaller segments
- **Time constraints**: Prioritize core materials
- **Assessment gaps**: Use multiple quiz formats

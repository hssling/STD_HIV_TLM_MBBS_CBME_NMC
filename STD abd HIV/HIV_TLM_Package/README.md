# HIV Dermatology Integration TLM Package

## Overview
This comprehensive Teaching-Learning Material (TLM) package integrates HIV education with dermatology concepts for MBBS 3rd year students. The package combines traditional teaching materials with innovative interactive content to enhance student engagement and clinical reasoning skills.

## Learning Objectives

After completing this TLM package, students will be able to:

1. Understand HIV epidemiology and transmission in Indian context
2. Recognize dermatological manifestations of HIV
3. Apply ABC approach to HIV prevention
4. Interpret CD4 counts and viral load monitoring
5. Make informed decisions about ART regimens
6. Counsel patients on HIV prevention and treatment

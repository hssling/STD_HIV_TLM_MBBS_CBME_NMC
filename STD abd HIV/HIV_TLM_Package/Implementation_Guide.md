# HIV Dermatology Integration Teaching-Learning Material (TLM) Package

## Overview
This comprehensive TLM package is designed for MBBS 3rd year students, integrating HIV education with dermatology concepts. The package includes interactive, multimedia, and traditional teaching materials to enhance student engagement and learning outcomes.

## Package Contents

### Handouts
- HIV_Dermatology_Integration_Handouts.md: Comprehensive handouts covering HIV-dermatology integration

### Visualizations
- hiv_dermatology_visualizations.py: Python script for generating visualizations
- abc_approach_icons.png, art_regimen_comparison.png, cd4_monitoring_chart.png, hiv_progression_timeline.png, indian_hiv_transmission_pie.png, prevention_pyramid.png, u_equals_u_symbol.png: Supporting images

### Video Scripts
- HIV_Dermatology_Video_Script.md: Script for video content delivery

### Quizzes
- HIV_Dermatology_Integration_MCQ_Quiz.py: Interactive MCQ quiz for assessment

### Interactive Materials
- clickable_diagram.html: Interactive anatomical diagrams
- case_study_decision_tree.html: Decision tree for case studies
- symptom_checker.html: Interactive symptom checker
- treatment_simulator.html: Treatment simulation tool
- interactive_quiz.html: Interactive quiz interface
- gamified_quiz.html: Gamified learning quiz
- multimedia_presentation.html: Multimedia presentation
- role_playing_scenario.html: Role-playing scenarios
- virtual_patient_simulation.html: Virtual patient simulation
- README.md: Interactive materials guide

### Presentations
- HIV_Class_Presentation.pptx: PowerPoint presentation for classroom use

### Scripts
- HIV_One_Hour_Class_Script.md: Detailed class script for 1-hour session

## Technical Requirements

### Software Requirements
- Python 3.7+ (for visualizations and quizzes)
- Web browser (Chrome/Firefox/Edge) for interactive HTML materials
- Microsoft PowerPoint or compatible software for presentations
- PDF reader for handouts

### Hardware Requirements
- Computer with internet access for interactive materials
- Projector/screen for presentations
- Audio system for video content

### Dependencies
- matplotlib (for Python visualizations)
- pandas (for data handling)
- streamlit (for interactive quizzes, optional)

## Implementation Instructions

### Pre-Class Preparation
1. Review all materials and ensure technical setup
2. Test interactive materials in target environment
3. Prepare handouts for distribution
4. Set up presentation equipment

### Class Structure (60 minutes)
1. Introduction (10 min): Use presentation slides 1-5
2. Core Content (20 min): Interactive visualizations and video
3. Case Studies (15 min): Use interactive decision trees
4. Assessment (10 min): MCQ quiz and discussion
5. Conclusion (5 min): Summary and Q&A

### Post-Class Activities
1. Assign interactive quizzes for self-assessment
2. Encourage use of symptom checker and treatment simulator
3. Review quiz results for learning analytics

## Usage Guidelines for Educators

### Best Practices
- Start with interactive elements to engage students
- Use real clinical cases when possible
- Encourage group discussions during interactive sessions
- Monitor student progress through quiz analytics

### Troubleshooting
- If Python scripts fail: Check Python installation and dependencies
- If interactive HTML fails: Ensure modern browser and JavaScript enabled
- If presentations don't load: Check PowerPoint version compatibility

### Customization
- Modify scripts to match local context
- Add institution-specific case studies
- Update statistics with current data

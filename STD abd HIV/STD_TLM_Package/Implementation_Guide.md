# STD Teaching-Learning Material (TLM) Package

## Overview
This comprehensive TLM package is designed for MBBS 3rd year students, covering Sexually Transmitted Diseases (STDs) with a focus on prevention, diagnosis, and management. The package includes interactive, multimedia, and traditional teaching materials to enhance student engagement and learning outcomes.

## Package Contents

### Handouts
- STD_Introduction_Handout.md: Introduction to STDs
- STD_Bacterial_STDs_Handout.md: Bacterial STDs coverage
- STD_Viral_STDs_Handout.md: Viral STDs coverage
- STD_Prevention_and_Control_Handout.md: Prevention strategies
- STD_Treatment_Protocols_Handout.md: Treatment guidelines
- STD_National_Programme_Linkage_Handout.md: National program integration

### Visualizations
- std_visualizations.py: Python script for generating visualizations
- global_std_epidemiology.png, std_classification.png: Supporting images

### Video Scripts
- STD_Class_Video_Script.md: Script for video content delivery

### Quizzes
- STD_Formative_Assessment_Quiz.py: Interactive formative assessment quiz

### Interactive Materials
- clickable_diagram.html: Interactive anatomical diagrams

### Scripts

## Technical Requirements

### Software Requirements
- Python 3.7+ (for visualizations and quizzes)
- Web browser (Chrome/Firefox/Edge) for interactive HTML materials
- Microsoft PowerPoint or compatible software for presentations
- PDF reader for handouts

### Hardware Requirements
- Computer with internet access for interactive materials
- Projector/screen for presentations
- Audio system for video content

### Dependencies
- matplotlib (for Python visualizations)
- pandas (for data handling)
- streamlit (for interactive quizzes, optional)

## Implementation Instructions

### Pre-Class Preparation
1. Review all materials and ensure technical setup
2. Test interactive materials in target environment
3. Prepare handouts for distribution
4. Set up presentation equipment

### Class Structure (60 minutes)
1. Introduction (10 min): Use presentation slides 1-5
2. Core Content (20 min): Interactive visualizations and video
3. Case Studies (15 min): Use interactive decision trees
4. Assessment (10 min): Formative quiz and discussion
5. Conclusion (5 min): Summary and Q&A

### Post-Class Activities
1. Assign interactive quizzes for self-assessment
2. Encourage use of symptom checker and treatment simulator
3. Review quiz results for learning analytics

## Usage Guidelines for Educators

### Best Practices
- Start with interactive elements to engage students
- Use real clinical cases when possible
- Encourage group discussions during interactive sessions
- Monitor student progress through quiz analytics

### Troubleshooting
- If Python scripts fail: Check Python installation and dependencies
- If interactive HTML fails: Ensure modern browser and JavaScript enabled
- If presentations don't load: Check PowerPoint version compatibility

### Customization
- Modify scripts to match local context
- Add institution-specific case studies
- Update statistics with current data

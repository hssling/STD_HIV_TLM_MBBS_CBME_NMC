# STD Teaching-Learning Material (TLM) Package

## Overview
This comprehensive Teaching-Learning Material (TLM) package covers Sexually Transmitted Diseases (STDs) for MBBS 3rd year students. The package combines traditional teaching materials with innovative interactive content to enhance student engagement and clinical reasoning skills in STD diagnosis and management.

- **Clickable Diagrams**: Anatomical exploration with pop-up information

- **Treatment Simulator**: Treatment regimen simulation
- **Gamified Prevention Game**: Interactive prevention education
- **Multimedia Timeline**: Historical STD developments

### Multimedia Content
- **Video Scripts**: Structured content for multimedia delivery
- **PowerPoint Presentations**: Visual classroom presentations

### Assessment Materials
- **Formative Assessment Quizzes**: Interactive assessment tools
- **Interactive Quizzes**: Immediate feedback systems
- **Role-Playing Counseling**: Communication skills practice

## Learning Objectives

After completing this TLM package, students will be able to:

1. Understand STD epidemiology and classification
2. Recognize clinical manifestations of common STDs
3. Apply appropriate diagnostic approaches
4. Select evidence-based treatment regimens
5. Counsel patients on prevention strategies
6. Link with national STD control programs

## Technical Requirements
